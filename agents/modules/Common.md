# Common 模块说明文档

## 概述
`Common` 模块位于 `Main/Modules/Common`，是 Blue Random 系统的跨模块底层基础设施中心。本模块承载了高性能无锁内存循环日志记录器（`AppLogger`）以及统一语义化版本与发布代号探测器（`AppVersion`），为所有业务模块与视图层提供日志诊断与版本元数据支撑。

---

## 功能清单

### 1. 全局环形日志系统 (`AppLogger`)
- **1. 标题**: `AppLogger`
- **2. 用途**: 为整个应用程序提供低开销、线程安全的分级日志记录。所有日志常驻于内存环形缓冲区中（默认保留最近 1000 条），并在控制台（Debug）中彩色输出，支持前端配置面板实时查询与文本导出。
- **3. 参数**:
  - `Info(string tag, string message)`: 记录常规信息日志。
  - `Warn(string tag, string message)`: 记录潜在异常或降级运行警告。
  - `Error(string tag, string message, Exception? ex = null)`: 记录严重错误及堆栈明细。
  - `GetLogs()`: 获取当前内存中全部格式化日志条目（按时间顺序）。
- **4. 注意事项**:
  - 内部采用 `ConcurrentQueue` 维护定长容量，超出阈值自动移出最旧的一条，杜绝长时间运行造成内存泄漏。
  - 不做同步磁盘写文件（零额外 IO 消耗），保证在 60fps 渲染及高频拖拽下日志记录依然耗时小于 1 微秒。

---

### 2. 应用语义化版本与代号管理 (`AppVersion`)
- **1. 标题**: `AppVersion`
- **2. 用途**: 动态定位并解析应用唯一的元数据源（根目录 `package.json`），向 C# 各层（启动屏、标题栏、更新服务）统一提供当前程序的版本号（`Version`）与发布代号（`Codename`）。
- **3. 参数**:
  - `Version` (`string`): 静态属性，返回当前语义化版本字符串（如 `"26.10.04"`）。
  - `Codename` (`string`): 静态属性，返回当前版本发布代号（如 `"Midori"`）。
  - `GetChangelog()`: 读取当前版本更新日志（优先内嵌清单 `changelog.md`，其次回溯磁盘）。
- **4. 注意事项**:
  - **双通道智能探测机制**:
    1. 优先尝试从 Assembly Manifest 读取内嵌资源 `package.json`（单文件独立打包或 CI 发布产物）；
    2. 若未内嵌（本地开发调试态），则从当前程序集基目录向上逐级回溯探测（最多探测 5 级父目录），确保源码修改版本号后本地 F5 即时生效，无需重复手动打包。
  - 作为全程序版本号的单一权威数据源，前端 `TabLogs.vue` 亦通过 Vite 别名直引根 `package.json`，确保前后端版本 100% 同步。
