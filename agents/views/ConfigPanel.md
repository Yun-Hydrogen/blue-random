# ConfigPanel 视图与页面说明文档

## 概述
`ConfigPanel` 位于 `Main/Views/ConfigPanel`（原生 WPF 窗体宿主）与 `WebUI/ConfigPanel`（Vue 3 + Vite + riz-ui 前端单页面应用）。作为系统的控制台界面，它承载完整的配置查看与修改、多班级名单录入、个性化多媒体素材上传、Windows 高级权限设定、运行日志诊断以及版本检测功能。

---

## 原生宿主窗体功能清单 (`ConfigPanelWindow`)

### 1. 窗口隐藏式秒开机制 (`OnWindowClosing`)
- **1. 标题**: `ConfigPanelWindow.OnWindowClosing` 隐藏式常驻设计
- **2. 用途**: 拦截用户的窗口关闭事件（如点击右上角 ✕ 按钮或快捷键关闭），取消窗口的实际销毁（Dispose），仅调用 `Hide()` 隐藏窗口。
- **3. 参数**:
  - `e` (`CancelEventArgs`): 窗体关闭事件参数，将 `e.Cancel` 设为 `true`。
  - **返回值** (`void`)。
- **4. 注意事项**:
  - 保持 Chromium (WebView2) 渲染上下文与 DOM 树驻留内存，使后续从系统托盘或右键菜单再次点击“配置”时能够实现 0 毫秒瞬间呼出，根除 Chromium 冷启动白屏。
  - 只有在收到 IPC `Destroy` 指令（整个程序彻底退出）时，才解除此拦截并彻底关闭窗体。

---

### 2. 窗口前台激活与焦点守卫 (`OnIpcMessageReceived -> ShowConfigPanel`)
- **1. 标题**: `ConfigPanelWindow` 前台激活与置顶抖动
- **2. 用途**: 响应来自托盘菜单或其他模块的 `ShowConfigPanel` 唤醒指令。将窗口从最小化还原，呼至 Windows 桌面最顶层并获取输入焦点。
- **3. 参数**:
  - `msg` (`IpcMessage`): 携带 `Command = "ShowConfigPanel"` 的消息包。
  - **返回值** (`void`)。
- **4. 注意事项**:
  - 采用 `Topmost = true; Topmost = false;` 的瞬态抖动模式，既能突破 Windows 系统的前台激活限制将配置面板带至最前，又不会霸道地永久锁定置顶，避免阻挡用户日常操作。
  - 若调用时 WebView2 尚未预热就绪，内部会自动触发 `EnsureReadyAsync()` 补充初始化。

---

## 前端选项卡页面功能清单 (`WebUI/ConfigPanel/views`)

### 3. 名单管理页面 (`TabRoster.vue`)
- **1. 标题**: 名单管理选项卡 (`TabRoster`)
- **2. 用途**: 提供多班级名单管理、学生名单表格录入、权重滑块调整、以及通过文本粘贴批量导入 TXT/CSV 学生名单。
- **3. 参数**:
  - 依赖 `useConfigPanel` 中的班级列表、当前班级 ID 以及导入解析对话框状态。
- **4. 注意事项**:
  - 单个学生权重范围为非负浮点数（默认 1.0）；权重设为 0 表示该学生暂不参与抽签（请假/轮空）。
  - 所有班级变动在前端确认后，通过 `nativeBridge.UpdateClassJson` 即时写入本地，无需手动点击全局保存。

---

### 4. 悬浮按钮设置页面 (`TabFloating.vue`)
- **1. 标题**: 悬浮按钮选项卡 (`TabFloating`)
- **2. 用途**: 定制常驻桌面的悬浮球外观与交互行为。包含按钮尺寸缩放（50% ~ 200%）、不透明度滑块、置顶开关、边框经典色与拾色器、自定义本地图标上传与预览、以及默认抽取人数预设（1 ~ 10 人）。
- **3. 参数**:
  - 绑定 `draft.floatingButton` 与 `draft.pickCountDialog` 配置草稿对象。
- **4. 注意事项**:
  - 上传自定义图标时会自动压缩并转为 Base64 调用 `SaveCustomResourceJson`，成功后绑定生成的资源 ID。
  - 调整默认抽取人数后，保存时会同步触发 `@FCB ApplyDefaultPickCount`，在悬浮按钮未展开时即时静默同步。

---

### 5. 结果浮窗设置页面 (`TabResult.vue`)
- **1. 标题**: 结果浮窗选项卡 (`TabResult`)
- **2. 用途**: 定制抽卡演播窗的视觉与听觉体验，以及配置常驻右上角的“结果暂留浮窗”。包括抽卡音效开关与自定义 WAV 上传、BGM 开关与自定义 MP3 上传及音量淡入时间调节；控制结果暂留浮窗开关、底色、边框、不透明度与自动关闭倒计时进度条。
- **3. 参数**:
  - 绑定 `draft.pickResultDialog` 配置草稿对象。
- **4. 注意事项**:
  - 版权音乐（BGM）与特殊抽卡音效不随仓库分发，页面提供友好的空态提示与自定义文件拖拽上传交互。
  - 暂留浮窗自动关闭时间设为 0 时表示“不自动关闭（常驻右上角）”，支持随时点击卡片右上角 ✕ 按钮滑出关闭。

---

### 6. 高级设置页面 (`TabAdvanced.vue`)
- **1. 标题**: 高级设置选项卡 (`TabAdvanced`)
- **2. 用途**: 集中管理 Windows 系统底层特权与教学防误改保护。支持一键开启/关闭计划任务免 UAC 开机自启、开启/关闭 UIAccess 特权置顶增强、设置/修改/注销 6 位管理员密码锁、以及一键恢复出厂设置。
- **3. 参数**:
  - 绑定 `draft.admin` 配置草稿及本地系统权限状态。
- **4. 注意事项**:
  - 开启 UIAccess 会强制要求管理员权限；开启后下次启动程序将具备穿透任何全屏窗口的顶级置顶特权。
  - 管理员密码锁定后，进入本页面或修改名单必须先输入正确密码解锁，防止课堂学生误操作。

---

### 7. 关于与更新页面 (`TabAbout.vue`)
- **1. 标题**: 关于选项卡 (`TabAbout`)
- **2. 用途**: 展示软件版本号、当前版本发布代号（如 Midori、Shiroko）、作者信息、开源协议（AGPLv3）、第三方资产版权免责声明，并提供一键在线检查更新按钮。
- **3. 参数**:
  - 调用 `nativeBridge.CheckForUpdatesAsync` 获取新版本检查结果。
- **4. 注意事项**:
  - 发现新版本时展示 Markdown 渲染的 Release 更新日志与直达 GitHub 下载页面的外部安全链接。

---

### 8. 运行日志页面 (`TabLogs.vue`)
- **1. 标题**: 运行日志选项卡 (`TabLogs`)
- **2. 用途**: 实时查看应用程序在后台产生的运行日志，支持日志级别过滤（All / Info / Warn / Error）、关键词搜索、一键复制到剪贴板以及一键导出为文本文件。
- **3. 参数**:
  - 调用 `nativeBridge.GetLogsJson` 定时拉取或手动刷新日志列表。
- **4. 注意事项**:
  - 本页面采用异步按需加载拆分（`tab-logs` chunk），避免日志相关的大体积高亮或格式化脚本拖慢配置面板首屏冷启动速度。
